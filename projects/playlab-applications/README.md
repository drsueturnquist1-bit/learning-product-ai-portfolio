# Playlab Application Documentation

**Status:** Planned; platform introduction and access are in progress  
**Purpose:** Document future AI application builds without overstating work that has not yet been completed

## Planned application 1: 3D Science Lesson Review Coach

Intended users: classroom teachers, curriculum reviewers, and science leaders.

Planned capabilities:

- Review lesson evidence against explicit three-dimensional science criteria
- Separate present, partial, missing, and unverifiable evidence
- Provide prioritized revision recommendations
- Refuse to invent lesson components or standards alignment
- Preserve human instructional judgment

## Planned application 2: Instructional Resource Quality Reviewer

Intended users: educators, curriculum teams, and learning-product teams.

Planned capabilities:

- Review alignment, rigor, inquiry, usability, inclusion, assessment, and implementation readiness
- Use a transparent quality rubric
- Explain the evidence behind each recommendation
- Flag uncertainty and missing inputs
- Produce an actionable improvement sequence
