# Sue Turnquist: Learning Product & AI Project Documentation

This repository documents selected learning products, curriculum systems, AI-assisted prototypes, testing practices, and revision decisions created by Sue Turnquist.

The purpose is to demonstrate product thinking and documentation discipline without exposing student information, school records, credentials, protected source code, or confidential audit findings.

## Documentation standards

Each project record includes:

1. Problem and audience
2. Sue’s role and responsibilities
3. Design decisions
4. Technology and workflow
5. Safety and accessibility considerations
6. Testing evidence
7. Known limitations
8. Revision history
9. Demonstration link when safe and available
